# Expense Auditor

יישום Web המקבל קבלות הוצאות (תמונות / PDF), מחלץ מהן נתונים אוטומטית באמצעות Claude, ומבצע ולידציה מול מדיניות ההוצאות של החברה. כל קבלה מקבלת פסיקה — **תואם** / **חורג** / **דורש בדיקה אנושית** — עם רשימת הפרות ונימוקים.

## הרצה מקומית

1. התקנת תלויות:

   ```bash
   npm install
   ```

2. הגדרת מפתח API: צרו קובץ `.env.local` בהשראת `.env.local.example` והוסיפו את מפתח Anthropic שלכם:

   ```bash
   cp .env.local.example .env.local
   # ולאחר מכן ערכו את .env.local והוסיפו:
   # ANTHROPIC_API_KEY=sk-ant-...
   ```

3. הרצת שרת הפיתוח:

   ```bash
   npm run dev
   ```

4. גשו ל-http://localhost:3000

## מודל

המודל בשימוש מוגדר בקבוע `MODEL` בקובץ `app/api/validate/route.ts`. ניתן להחליפו ל-`claude-opus-4-8` לדיוק מקסימלי.

## מדיניות ההוצאות

מדיניות ההוצאות המוטמעת באפליקציה (גרסה 3.1) מופיעה בקובץ `lib/policy.ts`, ומועברת ל-Claude כחלק מה-system prompt בקובץ `app/api/validate/route.ts`.

## כלל הברזל

האפליקציה לעולם לא מאשרת ("תואם") הוצאה שקיים בה ספק כלשהו — איכות תמונה נמוכה, שדה קריטי חסר, קטגוריה לא ברורה, או חריגה מהמדיניות שלא ניתן לאמת באופן חד-משמעי — במקרים אלו הפסיקה תמיד "דורש בדיקה אנושית".
